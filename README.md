## Зачем это

Одна и та же вещь на маркетплейсах стоит по-разному. PriceRadar открывает товар
на трёх площадках, сравнивает цены и показывает, где дешевле — с учётом кэшбэка
вашей карты.

И главное: приложение помогает **не покупать лишнего**. Список покупок с правилом
24 часов спрашивает через сутки: «всё ещё нужно?».

## Почему отдельное приложение, а не Telegram-бот

В России Telegram работает только через VPN, а маркетплейсы VPN блокируют.
Совместить их на одном телефоне нельзя: пока включён VPN — площадки не отвечают,
выключишь — не работает Telegram.

Поэтому PriceRadar — **самостоятельное приложение**. Оно открывает страницы
маркетплейсов во встроенном браузере телефона, то есть запросы уходят с обычного
российского IP. **VPN должен быть выключен.**

## Что умеет

- 🔎 Поиск по ссылке или названию — сразу на Wildberries, Ozon, Яндекс Маркете и М.Косметик (β).
- 💰 Сравнение цен и выгода «до N ₽».
- 🧭 Если площадка не ответила, под результатами видно, какая именно.
- 🔔 Отслеживание цены: проверка при открытии приложения и по кнопке «Обновить»,
  уведомление при снижении.
- 🕘 История поиска: последние запросы под строкой поиска.
- 📤 «Поделиться» ссылкой из приложения маркетплейса — PriceRadar сразу сравнит.
- 🔄 Уведомление о новой версии с GitHub.
- 💜 Список покупок с правилом 24 часов.
- 💳 Кэшбэк карты по площадкам — итоговая цена с его учётом.
- 📖 Встроенная инструкция и FAQ.
- 🔒 Без регистрации. Данные только на телефоне.

## Установка

1. Скачайте APK: **[PriceRadar.apk](https://github.com/luckyvoron-tech/priceradar/releases/latest/download/PriceRadar.apk)**
2. Откройте файл на телефоне.
3. Разрешите установку из неизвестных источников для файлового менеджера/браузера.
4. Готово. При первом запуске — короткая инструкция.

Требования: Android 8.0+ (minSdk 26).

## Как пользоваться

1. **Выключите VPN.** Без этого маркетплейсы блокируют запросы.
2. Вставьте ссылку на товар или напишите название.
3. Подождите 10–20 секунд — приложение откроет площадки.
4. Для косметики один раз выберите магазин: «Помощь» → «Выбрать магазин» (М.Косметик считает цены по нему).
5. Нажмите 🔔 у товара, чтобы следить за ценой, или 💜 — чтобы добавить в список.

## Честные ограничения

- **М.Косметик** — бета: цены считаются по выбранному магазину (кнопка в «Помощи»). Если магазин не выбран или сайт не ответил — площадка просто не попадает в сравнение.
- **Мегамаркет** почти всегда отдаёт капчу — в сравнении его нет.
- **Ozon** иногда включает антибот: если площадка не ответила, попробуйте ещё раз
  через минуту или вставьте прямую ссылку на товар.
- **Отслеживание** проверяет цены при открытии приложения (фоновая работа
  ограничена Android). Уведомление придёт, когда вы откроете приложение и цены
  обновятся.
- Цена на сайте может отличаться: карта, промокод, регион, остатки.
- Приложение не affiliated с маркетплейсами; покупка происходит на их сайте.

## Приватность

- Нет аккаунта, нет сервера, нет аналитики.
- Все данные (треки, список, кэшбэк) лежат в локальном хранилище приложения.
- Наружу уходят только запросы к самим маркетплейсам.

## Сборка

Проект собирается **без Gradle** — тем же тулчейном, что и ArendaLog:
JDK 17 + Android build-tools 34 + platform 35 в `C:\arendatools`.

```powershell
python tools\make_icons.py   # иконки
python tools\build.py        # dist\PriceRadar.apk
node tools\test_match.cjs    # проверка сопоставления товаров
```

Подпись — самоподписанный ключ `dist/priceradar-release-key.keystore`. Он **не публикуется**
(папка `dist/` в `.gitignore`): без него обновления «поверх» не встанут, поэтому храните
ключ и `dist/keystore.properties` на своей машине. Пароль можно задать через
`PRICERADAR_KS_PASS`.

## Структура

```
app/                 веб-ядро (HTML/CSS/JS, без сборки)
  index.html         экраны: поиск, цены, список, помощь
  app.css            тема
  js/store.js        локальное хранилище
  js/match.js        сопоставление «тот же товар»
  js/scrape.js       мост и экстракторы WB/Ozon/Яндекс
  js/ui.js           интерфейс
android/             тонкая оболочка WebView + мост
  src/.../MainActivity.java
tools/build.py       сборка APK: aapt2 → javac → d8 → zipalign → apksigner
docs/                страница приложения (GitHub Pages)
dist/                APK и ключ подписи
```

## Как это работает внутри

- Веб-интерфейс живёт на `https://priceradar.local` из assets (полноценный
  защищённый контекст, localStorage).
- Скрытый WebView открывает страницу площадки и выполняет там JS-экстрактор.
- Wildberries: внутренний JSON-поиск `__internal/u-search/v18` из контекста сайта.
- Ozon: composer-API `tileGridDesktop/mainState` из контекста сайта.
- Яндекс Маркет: JSON-LD `schema.org/Product` со страницы поиска.
- Сопоставление: три сигнала (модель, смысл, цена) + вето на Pro/Max, размеры,
  восстановленные товары.
