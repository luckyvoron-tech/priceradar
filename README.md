## Зачем это

Одна и та же вещь на площадках стоит по-разному. PriceRadar открывает товар
на нескольких площадках, сравнивает цены и показывает, где дешевле — с учётом
кэшбэка вашей карты.

И главное: приложение помогает **не покупать лишнего**. Список желаний с правилом
24 часов спрашивает через сутки: «всё ещё нужно?».

## Что умеет

- 🔎 Поиск по ссылке или названию — Wildberries, Яндекс Маркет, М.Косметик (β), Детский мир (β).
- 💰 Сравнение цен и выгода «до N ₽».
- 🧭 Если площадка не ответила, видно, какая именно.
- 🔔 Отслеживание цены, цена-цель и уведомление при снижении.
- 🕘 История поиска.
- 📤 «Поделиться» ссылкой из маркетплейса — PriceRadar сразу сравнит.
- 🔄 Уведомление о новой версии с GitHub.
- 💜 Список желаний с правилом 24 часов.
- 💳 Кэшбэк карты по площадкам.
- 🔒 Без регистрации. Данные только на телефоне.

## Честные ограничения

- **Ozon** блокирует автоматические запросы из WebView. Ссылку на Ozon можно
  открыть, но в сравнении его пока нет. Для полноценного Ozon нужен партнёрский
  фид или сервер с настоящим Chrome — это следующий этап.
- **М.Косметик** — бета: цены считаются по выбранному магазину.
- **Детский мир** — бета: подключается для детских запросов (игрушки, LEGO, коляски, подгузники и т.п.).
- **Мегамаркет** почти всегда отдаёт капчу — его нет.
- **Отслеживание** проверяет цены при открытии приложения (фон Android ограничен).
- Цена на сайте может отличаться: карта, промокод, регион, остатки.

## Монетизация

В `app/js/config.js` есть блок `affiliate`. После регистрации в Admitad
(или Яндекс Дистрибуции) вставьте партнёрские шаблоны:

```js
affiliate: {
  enabled: true,
  wildberries: { template: "https://ad.admitad.com/g/.../?ulp={target}&subid={subid}" },
  ozon:        { template: "https://ad.admitad.com/g/.../?ulp={target}&subid={subid}" },
  ymarket:     { template: "..." },
  magnit:      { template: "..." },
}
```

`{target}` — ссылка на товар, `{subid}` — метка приложения. Пока шаблон пуст,
ссылка открывается напрямую. Цена для покупателя не меняется; в приложении есть
раскрытие «партнёрские ссылки».

**Важно:** свои покупки и покупки семьи через свои ссылки — самовыкуп, Admitad
это запрещает. Монетизация рассчитана на независимых пользователей.

## Приватность

- Нет аккаунта, сервера и аналитики.

- Наружу уходят запросы к площадкам, GitHub (проверка обновления) и, если

## Сборка

Без Gradle — JDK 17 + Android build-tools 34 + platform 35 в `C:\arendatools`.

```powershell
python tools\make_icons.py   # иконки
python tools\build.py        # dist\PriceRadar.apk
node tools\test_match.cjs    # проверка сопоставления
```

Подпись — `dist/priceradar-release-key.keystore` + `dist/keystore.properties`
(не публикуются). Без них обновления «поверх» не встанут.

## Как это работает внутри

- Веб-интерфейс живёт на `https://priceradar.local` из assets.
- Скрытый WebView открывает страницу площадки и выполняет JS-экстрактор.
- Wildberries: внутренний JSON-поиск `__internal/u-search/v18`.
- Яндекс Маркет: JSON-LD `schema.org/Product`.
- М.Косметик: DOM страницы поиска (β).
- Детский мир: DOM страницы поиска и JSON-LD карточки (β).
- Сопоставление: модель, смысл, цена + вето на Pro/Max, размеры, восстановленные.
